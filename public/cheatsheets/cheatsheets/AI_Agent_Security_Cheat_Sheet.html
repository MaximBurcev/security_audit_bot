    Шпаргалка по безопасности ИИ-агентов¶

    Введение¶

    ИИ-агенты — это автономные системы на основе больших языковых моделей (LLM), способные рассуждать, планировать, использовать инструменты, хранить память и выполнять действия для достижения целей. Такой расширенный функционал порождает уникальные риски безопасности, выходящие за рамки традиционных атак на LLM через внедрение инструкций. Данная шпаргалка содержит рекомендации по защите архитектур ИИ-агентов и минимизации поверхности атаки.

    Ключевые риски¶

    • Внедрение инструкций (прямое и косвенное): Вредоносные инструкции, внедряемые через пользовательский ввод или внешние источники данных (сайты, документы, письма), перехватывающие управление агентом. (См. Шпаргалку по предотвращению внедрения инструкций в LLM)
    • Злоупотребление инструментами и повышение привилегий: Эксплуатация агентом избыточно разрешительных инструментов для выполнения непредусмотренных действий или доступа к неавторизованным ресурсам.
    • Утечка данных: Чувствительная информация, раскрываемая через вызовы инструментов, API-запросы или выводы агента.
    • Отравление памяти: Вредоносные данные, сохраняемые в памяти агента для влияния на будущие сессии или других пользователей.
    • Подмена целей: Манипулирование задачами агента в интересах злоумышленника под видом легитимной работы.
    • Избыточная автономия: Выполнение агентом высокорискованных действий без надлежащего человеческого контроля.
    • Каскадные сбои: Скомпрометированные агенты в мультиагентных системах, распространяющие атаки на другие агенты.
    • Истощение бюджета (DoW): Атаки, вызывающие чрезмерные расходы на API/вычисления через неограниченные циклы агента.
    • Раскрытие чувствительных данных: Персональные данные, учётные данные или конфиденциальная информация, случайно включённые в контекст агента или логи.

    Лучшие практики¶

    1. Безопасность инструментов и принцип минимальных привилегий¶

    • Предоставляйте агентам только минимальный набор инструментов, необходимых для конкретной задачи.
    • Реализуйте ограничение прав для каждого инструмента (только чтение vs. запись, конкретные ресурсы).
    • Используйте отдельные наборы инструментов для разных уровней доверия (например, внутренние и клиентские агенты).
    • Требуйте явного разрешения для чувствительных операций.

    Плохо: Избыточно разрешительная конфигурация инструментов¶

    # Опасно: агент имеет неограниченный доступ к оболочке
tools = [
    {
        "name": "execute_command",
        "description": "Execute any shell command",
        "allowed_commands": "*"  # Нет ограничений
    }
]

    Хорошо: Инструмент с ограниченным списком допустимых операций¶

    # Безопасно: ограничено конкретными безопасными командами
tools = [
    {
        "name": "file_reader",
        "description": "Read files from the reports directory",
        "allowed_paths": ["/app/reports/*"],
        "allowed_operations": ["read"],
        "blocked_patterns": ["*.env", "*.key", "*.pem", "*secret*"]
    }
]

    Пример промежуточного слоя авторизации инструментов (Python)¶

    from functools import wraps

SENSITIVE_TOOLS = ["send_email", "execute_code", "database_write", "file_delete"]

def require_confirmation(func):
    @wraps(func)
    async def wrapper(tool_name, params, context):
        if tool_name in SENSITIVE_TOOLS:
            if not context.get("user_confirmed"):
                return {
                    "status": "pending_confirmation",
                    "message": f"Action '{tool_name}' requires user approval",
                    "params": sanitize_for_display(params)
                }
        return await func(tool_name, params, context)
    return wrapper

    2. Валидация входных данных и защита от внедрения инструкций¶

    • Считайте все внешние данные ненадёжными (сообщения пользователей, извлечённые документы, ответы API, письма).
    • Выполняйте санитизацию входных данных перед включением внешнего контента в контекст агента.
    • Используйте разделители и чёткие границы между инструкциями и данными.
    • Применяйте контентную фильтрацию для известных паттернов внедрения.
    • Рассмотрите использование отдельных вызовов LLM для валидации/обобщения ненадёжного контента.

    Подробные техники см. в Шпаргалке по предотвращению внедрения инструкций в LLM.

    3. Безопасность памяти и контекста¶

    • Валидируйте и очищайте данные перед сохранением в памяти агента.
    • Реализуйте изоляцию памяти между пользователями и сессиями.
    • Устанавливайте сроки жизни и ограничения размера памяти.
    • Проверяйте содержимое памяти на наличие чувствительных данных перед сохранением.
    • Используйте криптографические проверки целостности для долгосрочной памяти.

    Плохо: Сохранение данных без валидации¶

    # Опасно: сохранение произвольного пользовательского ввода в постоянную память
def save_memory(agent, user_message, assistant_response):
    agent.memory.add({
        "user": user_message,  # Может содержать инъекцию
        "assistant": assistant_response,
        "timestamp": datetime.now()
    })

    Хорошо: Валидация и изоляция памяти¶

    import hashlib
from datetime import datetime, timedelta

class SecureAgentMemory:
    MAX_MEMORY_ITEMS = 100
    MAX_ITEM_LENGTH = 5000
    MEMORY_TTL_HOURS = 24

    def __init__(self, user_id: str, encryption_key: bytes):
        self.user_id = user_id
        self.encryption_key = encryption_key
        self.memories = []

    def add(self, content: str, memory_type: str = "conversation"):
        # Валидация контента
        if len(content) > self.MAX_ITEM_LENGTH:
            content = content[:self.MAX_ITEM_LENGTH]

        # Проверка на наличие чувствительных данных
        if self._contains_sensitive_data(content):
            content = self._redact_sensitive_data(content)

        # Проверка на попытки внедрения
        content = self._sanitize_injection_attempts(content)

        # Создание записи с проверкой целостности
        entry = {
            "content": content,
            "type": memory_type,
            "timestamp": datetime.utcnow().isoformat(),
            "user_id": self.user_id,
            "checksum": self._compute_checksum(content)
        }

        self.memories.append(entry)
        self._enforce_limits()

    def get_context(self) -> list:
        """Получить валидные, не истёкшие записи памяти."""
        valid_memories = []
        cutoff = datetime.utcnow() - timedelta(hours=self.MEMORY_TTL_HOURS)

        for mem in self.memories:
            mem_time = datetime.fromisoformat(mem["timestamp"])
            if mem_time > cutoff and self._verify_checksum(mem):
                valid_memories.append(mem["content"])

        return valid_memories

    def _contains_sensitive_data(self, content: str) -> bool:
        sensitive_patterns = [
            r'\b\d{3}-\d{2}-\d{4}\b',  # СНИЛС/SSN
            r'\b\d{16}\b',              # Номер карты
            r'password\s*[:=]\s*\S+',   # Пароли
            r'api[_-]?key\s*[:=]\s*\S+' # API-ключи
        ]
        return any(re.search(p, content, re.I) for p in sensitive_patterns)

    def _compute_checksum(self, content: str) -> str:
        return hashlib.sha256(
            (content + self.user_id).encode() + self.encryption_key
        ).hexdigest()[:16]

    4. Контроль с участием человека¶

    • Требуйте явного подтверждения для высокорискованных или необратимых действий.
    • Показывайте предпросмотр действий перед их выполнением.
    • Устанавливайте границы автономии в зависимости от уровня риска действия.
    • Ведите чёткий журнал решений и действий агента.
    • Предоставляйте пользователям возможность прерывать и откатывать операции агента.

    Классификация действий и процесс согласования¶

    from enum import Enum
from dataclasses import dataclass

class RiskLevel(Enum):
    LOW = "low"           # Операции чтения, безопасные запросы
    MEDIUM = "medium"     # Операции записи, вызовы API
    HIGH = "high"         # Финансы, удаление, внешние коммуникации
    CRITICAL = "critical" # Необратимые, критичные для безопасности

ACTION_RISK_MAPPING = {
    "search_documents": RiskLevel.LOW,
    "read_file": RiskLevel.LOW,
    "write_file": RiskLevel.MEDIUM,
    "send_email": RiskLevel.HIGH,
    "execute_code": RiskLevel.HIGH,
    "database_delete": RiskLevel.CRITICAL,
    "transfer_funds": RiskLevel.CRITICAL,
}

@dataclass
class PendingAction:
    action_id: str
    tool_name: str
    parameters: dict
    risk_level: RiskLevel
    explanation: str

class HumanInTheLoopController:
    def __init__(self, auto_approve_threshold: RiskLevel = RiskLevel.LOW):
        self.auto_approve_threshold = auto_approve_threshold
        self.pending_actions = {}

    async def request_action(self, tool_name: str, params: dict,
                            explanation: str) -> dict:
        risk_level = ACTION_RISK_MAPPING.get(tool_name, RiskLevel.HIGH)

        # Автоматическое одобрение низкорискованных действий
        if risk_level.value <= self.auto_approve_threshold.value:
            return {"approved": True, "auto": True}

        # Отправка на проверку человеком
        action = PendingAction(
            action_id=generate_uuid(),
            tool_name=tool_name,
            parameters=self._sanitize_params_for_display(params),
            risk_level=risk_level,
            explanation=explanation
        )

        self.pending_actions[action.action_id] = action

        return {
            "approved": False,
            "pending": True,
            "action_id": action.action_id,
            "requires": "human_approval",
            "risk_level": risk_level.value,
            "preview": self._generate_action_preview(action)
        }

    def _generate_action_preview(self, action: PendingAction) -> str:
        return f"""
        Действие: {action.tool_name}
        Уровень риска: {action.risk_level.value.upper()}
        Пояснение: {action.explanation}
        Параметры: {json.dumps(action.parameters, indent=2)}
        """

    5. Валидация выходных данных и защитные ограничения¶

    • Валидируйте выходные данные агента перед выполнением или отображением.
    • Применяйте фильтрацию выходных данных для предотвращения утечки чувствительной информации.
    • Используйте структурированные выходные данные со схемной валидацией там, где это возможно.
    • Устанавливайте ограничения на действия (лимиты запросов, ограничения области).
    • Применяйте фильтры безопасности контента к генерируемым ответам.

    Конвейер валидации выходных данных¶

    from pydantic import BaseModel, validator
from typing import Optional, List

class AgentToolCall(BaseModel):
    tool_name: str
    parameters: dict
    reasoning: Optional[str]

    @validator('tool_name')
    def validate_tool_allowed(cls, v):
        allowed_tools = ["search", "read_file", "calculator", "get_weather"]
        if v not in allowed_tools:
            raise ValueError(f"Tool '{v}' is not in allowed list")
        return v

    @validator('parameters')
    def validate_no_sensitive_data(cls, v):
        sensitive_patterns = [
            r'api[_-]?key', r'password', r'secret', r'token',
            r'credential', r'private[_-]?key'
        ]
        params_str = json.dumps(v).lower()
        for pattern in sensitive_patterns:
            if re.search(pattern, params_str):
                raise ValueError("Parameters contain potentially sensitive data")
        return v

class OutputGuardrails:
    def __init__(self):
        self.pii_patterns = self._load_pii_patterns()
        self.blocked_actions = set()
        self.rate_limiter = RateLimiter(max_calls=100, window_seconds=60)

    async def validate_output(self, agent_output: dict) -> dict:
        # Проверка лимитов запросов
        if not self.rate_limiter.allow():
            raise RateLimitExceeded("Agent action rate limit exceeded")

        # Валидация структуры
        if "tool_calls" in agent_output:
            for call in agent_output["tool_calls"]:
                validated = AgentToolCall(**call)

        # Фильтрация персональных данных из ответов
        if "response" in agent_output:
            agent_output["response"] = self._filter_pii(agent_output["response"])

        # Проверка на попытки утечки данных
        if self._detect_exfiltration_attempt(agent_output):
            raise SecurityViolation("Potential data exfiltration detected")

        return agent_output

    def _detect_exfiltration_attempt(self, output: dict) -> bool:
        """Обнаружение попыток утечки данных через вызовы инструментов."""
        suspicious_patterns = [
            # Кодирование чувствительных данных в URL
            lambda o: "http" in str(o) and any(
                p in str(o).lower() for p in ["base64", "encode", "password"]
            ),
            # Большой объём данных в вебхуках/API-вызовах
            lambda o: o.get("tool_name") in ["http_request", "webhook"] and
                     len(str(o.get("parameters", ""))) > 10000,
        ]
        return any(pattern(output) for pattern in suspicious_patterns)

    6. Мониторинг и наблюдаемость¶

    • Логируйте все решения агента, вызовы инструментов и их результаты.
    • Реализуйте обнаружение аномалий для выявления необычного поведения агента.
    • Отслеживайте потребление токенов и затраты на сессию/пользователя.
    • Настройте оповещения о событиях, важных для безопасности.

    import structlog
from dataclasses import dataclass, field
from typing import List, Dict, Any
from datetime import datetime

logger = structlog.get_logger()

@dataclass
class AgentSecurityEvent:
    event_type: str
    severity: str  # INFO, WARNING, CRITICAL
    agent_id: str
    session_id: str
    user_id: str
    timestamp: datetime
    details: Dict[str, Any]
    tool_name: Optional[str] = None

class AgentMonitor:
    ANOMALY_THRESHOLDS = {
        "tool_calls_per_minute": 30,
        "failed_tool_calls": 5,
        "injection_attempts": 1,
        "sensitive_data_access": 3,
        "cost_per_session_usd": 10.0,
    }

    def __init__(self, agent_id: str):
        self.agent_id = agent_id
        self.session_metrics = {}
        self.alert_handlers = []

    async def log_tool_call(self, session_id: str, tool_name: str,
                           params: dict, result: dict, user_id: str):
        # Скрыть чувствительные данные перед логированием
        safe_params = self._redact_sensitive(params)
        safe_result = self._redact_sensitive(result)

        event = AgentSecurityEvent(
            event_type="tool_call",
            severity="INFO",
            agent_id=self.agent_id,
            session_id=session_id,
            user_id=user_id,
            timestamp=datetime.utcnow(),
            tool_name=tool_name,
            details={
                "parameters": safe_params,
                "result_status": result.get("status"),
                "execution_time_ms": result.get("execution_time_ms"),
            }
        )

        await self._emit_event(event)
        await self._check_anomalies(session_id, event)

    async def log_security_event(self, session_id: str, event_type: str,
                                  severity: str, details: dict, user_id: str):
        event = AgentSecurityEvent(
            event_type=event_type,
            severity=severity,
            agent_id=self.agent_id,
            session_id=session_id,
            user_id=user_id,
            timestamp=datetime.utcnow(),
            details=details
        )

        await self._emit_event(event)

        if severity == "CRITICAL":
            await self._trigger_alert(event)

    async def _check_anomalies(self, session_id: str, event: AgentSecurityEvent):
        metrics = self.session_metrics.setdefault(session_id, {
            "tool_calls": [],
            "failed_calls": 0,
            "total_cost": 0.0,
        })

        metrics["tool_calls"].append(datetime.utcnow())

        # Проверка частоты вызовов инструментов
        recent_calls = [t for t in metrics["tool_calls"]
                       if (datetime.utcnow() - t).seconds < 60]
        if len(recent_calls) > self.ANOMALY_THRESHOLDS["tool_calls_per_minute"]:
            await self.log_security_event(
                session_id, "anomaly_detected", "WARNING",
                {"reason": "excessive_tool_calls", "count": len(recent_calls)},
                event.user_id
            )

    def _redact_sensitive(self, data: dict) -> dict:
        """Скрыть чувствительные поля в данных логов."""
        sensitive_keys = {"password", "api_key", "token", "secret", "credential"}

        def redact(obj):
            if isinstance(obj, dict):
                return {
                    k: "***REDACTED***" if k.lower() in sensitive_keys else redact(v)
                    for k, v in obj.items()
                }
            elif isinstance(obj, list):
                return [redact(i) for i in obj]
            return obj

        return redact(data)

    Защищённые коммуникации в мультиагентной системе¶

    from typing import Optional
import jwt
from datetime import datetime, timedelta

class AgentTrustLevel(Enum):
    UNTRUSTED = 0
    INTERNAL = 1
    PRIVILEGED = 2
    SYSTEM = 3

class SecureAgentBus:
    """Защищённый коммуникационный слой для мультиагентных систем."""

    def __init__(self, signing_key: bytes):
        self.signing_key = signing_key
        self.agent_registry = {}
        self.message_validators = []
        self.circuit_breakers = {}

    def register_agent(self, agent_id: str, trust_level: AgentTrustLevel,
                       allowed_recipients: List[str]):
        self.agent_registry[agent_id] = {
            "trust_level": trust_level,
            "allowed_recipients": allowed_recipients,
            "allowed_message_types": self._get_allowed_types(trust_level)
        }
        self.circuit_breakers[agent_id] = CircuitBreaker(
            failure_threshold=5,
            recovery_timeout=60
        )

    async def send_message(self, sender_id: str, recipient_id: str,
                          message_type: str, payload: dict) -> dict:
        # Валидация отправителя
        sender = self.agent_registry.get(sender_id)
        if not sender:
            raise SecurityViolation(f"Unknown sender agent: {sender_id}")

        # Проверка автоматического выключателя
        if self.circuit_breakers[sender_id].is_open:
            raise CircuitBreakerOpen(f"Agent {sender_id} is temporarily blocked")

        # Проверка авторизации получателя
        if recipient_id not in sender["allowed_recipients"]:
            await self._log_security_event(
                "unauthorized_message_attempt",
                {"sender": sender_id, "recipient": recipient_id}
            )
            raise SecurityViolation("Sender not authorized to message recipient")

        # Валидация типа сообщения
        if message_type not in sender["allowed_message_types"]:
            raise SecurityViolation(f"Message type '{message_type}' not allowed")

        # Санитизация полезной нагрузки
        sanitized_payload = self._sanitize_payload(payload, sender["trust_level"])

        # Создание подписанного сообщения
        signed_message = {
            "sender": sender_id,
            "recipient": recipient_id,
            "type": message_type,
            "payload": sanitized_payload,
            "timestamp": datetime.utcnow().isoformat(),
            "signature": self._sign_message(sender_id, recipient_id,
                                           message_type, sanitized_payload)
        }

        return signed_message

    async def receive_message(self, recipient_id: str, message: dict) -> dict:
        # Проверка подписи
        if not self._verify_signature(message):
            raise SecurityViolation("Invalid message signature")

        # Проверка актуальности сообщения (защита от replay-атак)
        msg_time = datetime.fromisoformat(message["timestamp"])
        if (datetime.utcnow() - msg_time) > timedelta(minutes=5):
            raise SecurityViolation("Message expired (possible replay attack)")

        # Валидация получателя
        if message["recipient"] != recipient_id:
            raise SecurityViolation("Message recipient mismatch")

        return message["payload"]

    def _sanitize_payload(self, payload: dict, trust_level: AgentTrustLevel) -> dict:
        """Удалить чувствительные данные в зависимости от уровня доверия."""
        if trust_level < AgentTrustLevel.PRIVILEGED:
            # Удалить системные поля для агентов с низким уровнем доверия
            payload = {k: v for k, v in payload.items()
                      if not k.startswith("_system")}

        # Всегда очищать потенциально вредоносный контент
        return sanitize_untrusted_content(payload)

    Классификация данных и их обработка¶

    from enum import Enum
from typing import Callable

class DataClassification(Enum):
    PUBLIC = "public"
    INTERNAL = "internal"
    CONFIDENTIAL = "confidential"
    RESTRICTED = "restricted"  # Персональные данные, финансовая, медицинская информация

class DataProtectionPolicy:
    def __init__(self):
        self.classification_rules = []
        self.handling_rules = {}

    def classify_data(self, data: str, context: dict) -> DataClassification:
        """Автоматическая классификация данных по паттернам содержимого."""
        patterns = {
            DataClassification.RESTRICTED: [
                r'\b\d{3}-\d{2}-\d{4}\b',      # СНИЛС/SSN
                r'\b\d{16}\b',                  # Номер карты
                r'\b[A-Z]{2}\d{6,9}\b',         # Паспорт
                r'diagnosis|prescription|patient',  # Медицинские данные
            ],
            DataClassification.CONFIDENTIAL: [
                r'salary|compensation|bonus',
                r'api[_-]?key|password|secret',
                r'confidential|internal only',
            ],
            DataClassification.INTERNAL: [
                r'@company\.com',
                r'internal|draft|not for distribution',
            ]
        }

        for classification, pattern_list in patterns.items():
            if any(re.search(p, data, re.I) for p in pattern_list):
                return classification

        return DataClassification.PUBLIC

    def apply_protection(self, data: str, classification: DataClassification,
                         operation: str) -> str:
        """Применить соответствующую защиту в зависимости от классификации."""
        handlers = {
            DataClassification.RESTRICTED: {
                "include_in_context": self._redact_fully,
                "log": self._redact_fully,
                "output": self._redact_fully,
            },
            DataClassification.CONFIDENTIAL: {
                "include_in_context": self._mask_partially,
                "log": self._redact_fully,
                "output": self._mask_partially,
            },
            DataClassification.INTERNAL: {
                "include_in_context": lambda x: x,
                "log": self._mask_partially,
                "output": lambda x: x,
            },
        }

        handler = handlers.get(classification, {}).get(operation, lambda x: x)
        return handler(data)

    def _redact_fully(self, data: str) -> str:
        return "[REDACTED]"

    def _mask_partially(self, data: str) -> str:
        if len(data) <= 4:
            return "****"
        return data[:2] + "*" * (len(data) - 4) + data[-2:]


# Использование при формировании контекста агента
class SecureContextBuilder:
    def __init__(self, policy: DataProtectionPolicy):
        self.policy = policy

    def build_context(self, documents: List[str], max_tokens: int = 4000) -> str:
        protected_docs = []

        for doc in documents:
            classification = self.policy.classify_data(doc, {})
            protected = self.policy.apply_protection(
                doc, classification, "include_in_context"
            )
            protected_docs.append(protected)

        # Объединение и обрезка
        context = "\n---\n".join(protected_docs)
        return context[:max_tokens * 4]  # Приблизительная оценка символов

    Рекомендации и запреты¶

    Рекомендуется:

    • Применять принцип минимальных привилегий ко всем инструментам и разрешениям агента.
    • Валидировать и очищать все внешние входные данные (сообщения пользователей, документы, ответы API).
    • Реализовывать контроль с участием человека для высокорискованных действий.
    • Изолировать память и контекст между пользователями и сессиями.
    • Вести мониторинг поведения агента и настраивать обнаружение аномалий.
    • Использовать структурированные выходные данные со схемной валидацией.
    • Подписывать и проверять межагентные коммуникации.
    • Классифицировать данные и применять соответствующие защитные меры.

    Запрещается:

    • Давать агентам неограниченный доступ к инструментам или разрешения с шаблоном *.
    • Доверять контенту из внешних источников (сайты, письма, документы).
    • Разрешать агентам выполнять произвольный код без изоляции (sandbox).
    • Хранить чувствительные данные в памяти агента без шифрования/маскирования.
    • Допускать принятие агентом высокорискованных решений без контроля человека.
    • Игнорировать контроль затрат (неограниченные циклы могут привести к истощению бюджета).
    • Передавать неочищенные данные между агентами в мультиагентных системах.
    • Логировать чувствительные данные (персональные данные, учётные данные) в открытом виде.
